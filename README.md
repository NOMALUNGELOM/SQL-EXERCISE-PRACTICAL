# SQL-EXERCISE-PRACTICAL

This repository contains a collection of SQL exercises and practicals completed using Snowflake’s cloud data platform. Each folder focuses on specific SQL concepts, from basic SELECT statements to advanced date and null handling functions. All exercises include objectives, Hand written SQL code and result outputs.

# Exercise 1 - SQL Fundamentals (SELECT & Filtering Statements)
Focus: Basic SQL queries to extract and filter data using the SELECT and WHERE clauses. 
Objective: Understand how to retrieve specific columns, apply conditions, and use logical operators.

# Exercise 2 - SQL Fundamentals (Aggregate Functions & Grouping)
Focus: Use of SQL aggregate functions and GROUP BY statements for summarizing data. 
Objective: Learn to calculate totals, averages, counts, and apply group-level analysis.

# Exercise 3 - SQL Fundamentals (CASE Statements)
Focus: Working with conditional logic in SQL using the CASE statement. 
Objective: Classify data into categories or derive new columns based on conditions.

# Exercise 4 - SQL JOIN Exercise
Focus: Combining multiple tables using different join types (INNER JOIN, LEFT JOIN, RIGHT JOIN, FULL JOIN). 
Objective: Understand relational data and perform joins to answer business questions.

# Exercise 5 - Advanced SQL (DATE FUNCTIONS)
Focus: Manipulating and analyzing date and time data in SQL. 
Objective: Learn how to use functions like DATE_PART, DATEADD, and DATEDIFF for time-based analysis.

# Exercise 6 - Advanced SQL (NULL FUNCTIONS)
Focus: Handling missing values using COALESCE, NVL, and NULLIF. 
Objective: Understand how to replace or compare null values in SQL queries.

# Exercise 7 - SQL Fundamentals (UNION & UNION ALL)
Focus: Combining multiple query results into a single dataset. 
Objective: Understand the difference between UNION and UNION ALL, and when to use each.

# Practical 1 - SQL Fundamentals (Snowflake Basic SQL Syntax)
Focus: Executing simple SQL commands within Snowflake. 
Objective: Familiarize with Snowflake environment setup, database creation, and data querying.
